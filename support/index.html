How can we help?

Questions, installation help and content feedback.

Questions and feedback on GitHub

GitHub issues are public and require a GitHub account to post. A grown-up should post feedback. Do not share a child's name, photo, voice, school, device identifier or private reading history.

Privacy and private support

Email 723156735@qq.com for privacy requests or anything you do not want to post publicly. Include only the information needed to explain your request.

Report unsuitable content

Send the activity or book title, the part that needs attention, and your app version. Please avoid attaching children's personal data. We review reports and can remove content from the beta catalog.

The library looks empty

Connect to the internet and pull down on the shelf to refresh. The external beta has its own reviewed content selection, so it may contain fewer items than an internal build.

Camera or microphone access

Only activities that need capture ask for permission. You can decline access or change it in Settings. Close the activity to stop capture. Please tell us if an activity does not offer a suitable way to continue after you decline.

TestFlight builds expire

Each build can be tested for up to 90 days. Use TestFlight to install a newer build when one is available. A testing link can stop accepting new testers or reach its tester limit.
